A escolha para uso de métodos recursivos é que o problema de arvores binárias é por si só recursivo, portanto se tornando assim mais natural e lógico o uso da recursão.
Além disso, evita a repetição excessiva de loops de repição.
Em métodos menores como um menorDosMaiores, utilizei o laço while pois era uma lógica básica de ser implementada utilizando um método dinâmico.
